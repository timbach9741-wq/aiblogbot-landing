  • 신청서로 받은 이름·연락처는 체험 안내, 상담, 이용권 발급에만 씁니다.

  • 개인정보를 팔지 않습니다. 새 기능·할인 소식은 신청서에서 따로 동의(선택)하신 분께만 보냅니다.

1. 수집하는 개인정보와 목적

언제수집 항목목적
홈페이지 신청서 작성 시이름(또는 상호), 연락 방법, 연락처, 업종, 선택한 이용권, 문의 내용무료체험·구매 상담, 설치 지원, 입금 확인, 이용권(활성화 코드) 발급
프로그램 안의 [이용권 구매] 버튼으로 신청 시위 항목 + PC 고유번호해당 PC에 이용권을 발급하기 위해
프로그램 사용 중PC 고유번호, 무료체험 사용 횟수와 사용 시각무료체험 3회 제한, 체험 완료 할인 대상 확인
글 작성(발행 준비)이 끝날 때마다PC 고유번호, 프로그램 버전, 이용권 종류, 성공/실패 여부, 시각 (글 내용은 보내지 않음)사용 현황 확인, 오래 쓰지 않는 고객 지원, 정부 지원사업 활용도 점검 자료
신청서에서 선택 동의 시연락처, 동의 여부와 동의 시각새 기능·할인 등 광고성 정보를 문자·카카오톡으로 안내 (동의하지 않아도 신청·이용에 영향 없음)
활성화 코드 등록 시PC 고유번호, 활성화 코드, 등록일이용권을 해당 PC에 등록하고 이용 기간 계산
프로그램 오류 발생 시PC 고유번호, 프로그램 버전, 오류가 난 단계, 오류 내용오류 원인 확인과 고객 지원

※ PC 고유번호는 컴퓨터 네트워크 장치의 고유 번호(MAC 주소)로, 이름이나 연락처 없이는 개인을 알아볼 수 없는 정보입니다.

2. 저희가 받지 않는 정보

  • 네이버 아이디·비밀번호, Google Gemini API 키: 이용자 PC 안에만 암호화해 저장하며 저희 서버로 보내지 않습니다.
  • 블로그 글에 쓰는 사진과 업종 정보: 이용자가 직접 발급한 Gemini API 키를 통해 Google로 직접 전송되어 글을 만드는 데 쓰입니다. 저희는 이 내용을 받거나 저장하지 않습니다. Google의 처리 방식은 Google 개인정보처리방침을 따릅니다.
